# Sparse-anchor microgrid profile data

This is a fully synthetic, unlabeled tabular dataset created for a cross-neighborhood profile-discovery challenge. It contains 24 anonymous sites observed over 240 days. Sites are drawn from eight recurring operating-profile families, with three independent site instances per family. The CSV intentionally contains no profile labels or district-type column.

The challenge preparation uses two sites per profile for public training and holds the third site per profile out for evaluation. Measurements include shared weather conditions and noisy demand-response indicators. Later-period observations include temporal drift. The data includes a small number of missing measurements.

All values are generated for this challenge and are released under CC0 1.0 Universal. No real customer, utility, or location data is included.
